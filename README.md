# Orwell

Big Brother is watching you.

## Building

Orwell depends on RMLMapper 8.1 to map the input data into an RDF Graph. Download it [here](https://github.com/RMLio/rmlmapper-java/releases/tag/v8.1.0), rename it to `rmlmapper.jar` and place it in `data/`.

## Running

```sh
./gradlew build
./gradlew run
```
